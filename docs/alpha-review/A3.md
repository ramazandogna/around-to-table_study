# A3 UI/UX & accessibility audit (desktop 1440x900, iPhone 13 390x664)

Tested: sign-in, creator, hall, HUD, calendar, empty friends, Turkish, Tab and Esc. Not tested: real on-screen keyboard, door error text, disconnect banner, timer HUD.

- [A3-1][P2][a11y] Dialogs never take focus: after opening the calendar focus stays on the HUD clock, with no Tab trap — ui/Panel.tsx:34, ui/Calendar.tsx:158 — focus the first control, trap Tab, restore on close.
- [A3-2][P2][a11y] Esc works only in Calendar, Intro, Status, Games, TableGames, Discovery, ExitGame; Friends, Phone, Goals ignore it — grep Escape in ui/ — one shared Esc-to-close.
- [A3-3][P2][mobile] Friends panel collides with the "Room chat" button, which covers its close X — A3-ph-7-Arka — hide the chat toggle while a panel is open.
- [A3-4][P2][mobile] Opened phone menu stays over other panels and hides the calendar title — A3-ph-7-Takv — close the menu when a panel opens.
- [A3-5][P2][mobile] Phone chat input shrinks to about 100px; placeholder reads "say somet!" (TR "bir şey s") — styles.css:4096-4110, A3-ph-4-hall — shorter placeholder or a wider input.
- [A3-6][P2][mobile] Phone menu is 10 emoji-only buttons (globe, door, question mark) — A3-ph-5-menu — add visible labels or tooltips.
- [A3-7][P2][mobile] Welcome coach card fills a third of the phone screen beside the joystick; "Got it" is 53x32 — A3-ph-4-hall — shorten to one line, 44px button.
- [A3-8][P3][a11y] Touch targets under 44px: HUD buttons 36px, name tags 16px, chat close 28px, music close 22px, quests row 17px — A3-desk-4-hall — enlarge hit areas on coarse pointers.
- [A3-9][P2][ux] Coach says "straight ahead through the glass doors" but never names the smoking room; the Library sign is half cut off on phone — A3-desk-4-hall, A3-ph-4-hall — name both rooms in the coach and keep area labels on screen.
- [A3-10][P3][ux] Intro note appears seconds after the canvas, then the coach card follows: two welcomes in a row — A3-desk-3-intro — show one.
- [A3-11][P2][ux] Desktop HUD has 11 equal-weight buttons; Exit and Sign out sit beside Phone — A3-desk-4-hall — move sound, language, about, exit, sign out into a "More" menu.
- [A3-12][P3][a11y] Controls hint is 12px at 0.6 opacity over the scene — styles.css:545-549 — raise opacity, add a text shadow.
- [A3-13][P3][a11y] Chat placeholder at 0.7 opacity on soft ink is likely under 4.5:1 — styles.css:862-865 — use full ink-soft.
- [A3-14][P3][i18n] Language switch reloads the page and loses chat and position — i18n/t.ts:37-43 — warn first or update live. Turkish text itself fits on desktop and in panels.
- [A3-15][P3][a11y] Joystick is role="application" with no screen-reader alternative; Tab order starts at name tags — ui/Joystick.tsx:45 — put chat input first in Tab order.
- [A3-16][P3][visual] Desktop chat panel is translucent over the scene and hides the Elevator label; emoji floods get hard to read — A3-desk-7-Arka — more opaque background.
- Good: empty friends list has a clear hint; the calendar reads well in Turkish; the creator uses radiogroups.
