Production build via vite preview at /around-to-table_study/, Lighthouse 13. Raw: W2-lighthouse-before.json. Shots: shots/W2-*.png.

|---|---|---|
| Performance | 89 | 100 |

Mobile: LCP 0.9 s, TBT 445 ms, 415 KB. External hosts were unreachable from the sandbox, so those links were checked in source only.

## Funnel
Hero -> "Play on the web" -> beta modal -> "See the game" -> code door -> Google sign-in -> name, look, pet -> hall. Drop-offs: (1) hero click (promise vs invite-only); (2) modal code wall; (3) code arrives later by email; (4) Google consent.

## Findings
[W2-1][P0][funnel] Play CTAs are real links to the game, but the click opens a modal; ctrl/middle-click, no-JS or a slow hydrate skip the modal and land at the code door cold — App.vue:250,324 — keep the href but point it at `#beta` and open the modal from there.
[W2-2][P0][funnel] The only way to get a code is a mailto with the owner's address; phones without a mail app dead-end, and nothing captures interest — App.vue:68-70, PlayGate.vue:75 — add a small waitlist form or a copy-address button with the address shown.
[W2-3][P1][seo] og:image is a relative URL ("logo.png"), so Facebook, X and Slack show no preview; there is no og:url, og:type, twitter:card or canonical link — site/index.html:17 — use the absolute https://<user>.github.io/around-to-table_study/ URL for og:image and add og:url, twitter:card=summary_large_image and canonical.
[W2-5][P1][seo] There is no robots.txt, sitemap.xml or 404.html; Pages serves its own 404 for unknown paths — site/public — add robots.txt and sitemap.xml pointing to the base URL, plus a simple 404.html.
[W2-6][P1][a11y] Play buttons have no accessible name on mobile because the label is hidden below sm and the icon is aria-hidden — App.vue:250-257 — add an aria-label from copy.nav.play.
[W2-7][P1][a11y] The "Coming soon" store badges are spans with tabindex and aria-label, which is prohibited ARIA, and the language button's aria-label does not contain its visible text "EN" — App.vue:332-340, :206-213 — drop the aria-label on the spans (use visible text) and make the label include the visible language name.
[W2-8][P1][perf] Mobile TBT is 445 ms (score 0.63) from rei-kit, 178 KB of CSS and the hero animations; the 129 KB JS bundle includes unused vue-router — site/package.json:15, App.vue effects — remove vue-router, and defer the cursor, sound and bubble scripts until after first paint.
[W2-10][P1][seo] Language is chosen only from localStorage (default English), with no URL or hreflang, so TR/ZH/JA pages cannot be linked or indexed and a TR visitor lands on English — i18n.ts:455-474 — read navigator.language on first visit and consider ?lang= or /tr/ paths.
[W2-11][P1][ux] The footer terms and privacy links go to the game origin (workers.dev), not the site, so the legal pages live and die with the Worker, and the footer links to a raw github.com profile — App.vue:603-610 — copy terms.html and privacy.html into site/public and link relatively.
